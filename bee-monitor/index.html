網站如何更新

監測程式仍在 Windows 端保存完整照片；本網站只放最近 20 張照片。重新匯出並部署後，較舊的網站照片會從下一版清單移除，本機原始檔不受影響。研究報告只保存在使用者電腦。

GitHub Pages 是公開的靜態網站，不能執行原本的 Flask、MQTT、登入、即時影像或遠端控制。需要這些功能時，請使用另行運行的監測後端。
