# 首爾好行 Seoul Easy

為台灣旅客設計的韓國地點搜尋與地鐵轉乘 MVP。

## 立即試用

直接以瀏覽器開啟 `index.html`。目前內建景福宮、廣藏市場、弘大、聖水洞及明洞等示範資料。

## 目前功能

- 以繁體中文搜尋韓國景點
- 顯示中、韓、英三語名稱與韓文地址
- 顯示地鐵線色、車站編號、搭乘方向與轉乘提示
- 複製韓文名稱及地址
- 開啟 Naver Map 搜尋結果
- 手機與桌面響應式介面

## 正式版待串接

- 後端代理 Google Places Text Search（API 金鑰不可放在前端）
- Google Routes Transit 或授權交通資料
- 完整車站名稱、路線、線色與出口資料庫
- 起點定位、即時營運資訊、收藏持久化及離線地圖

## GitHub Pages

此專案可直接由 repository 根目錄發布，不需要建置指令。GitHub repository 的 Pages 設定選擇 `Deploy from a branch`、`main`、`/(root)`。

## 地圖素材政策

壓縮檔中的地鐵圖來自第三方公開下載，但未確認再利用授權，因此不會複製、內嵌或隨本專案散布。App 僅使用自行設計的路線介面；正式地圖與交通資料應使用具備相應授權的 API 或開放資料。
